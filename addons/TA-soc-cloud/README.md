# TA-soc-cloud v1.2
Parsing JSON + mapping CIM **partiel** (Authentication, Change) pour AWS, Azure, GCP, M365 et SaaS.
Le mapping « Change » est volontairement incomplet (champs `object_category`, `status`, `command`...) : c'est l'exercice E5 bonus.
Données synthétiques, pas des exports officiels des fournisseurs.
