# Exercices

Un exercice = un **objectif**, des **livrables** (preuves dans votre dossier `preuves/`), des **étapes** numérotées, des **indices** à ouvrir *seulement si vous êtes bloqué* (niveau 1 = direction, 2 = commande, 3 = presque la réponse), et des **critères de réussite**.
Le corrigé est dans `../instructor/ANSWER-KEY.md` — ouvrez-le **après** avoir essayé.

| Exercice | Module | Sujet |
|---|---|---|
| E0 | M0 | Architecture, contrat d'intake, menaces, volumétrie |
| E1 | M1 | Agent UF : ajouter une source, prouver la reprise, diagnostiquer un UF muet |
| E2 | M2 | Collecteur Syslog : routage, droits, rotation, mesure de perte |
| E3 | M3 | API/HEC : poller robuste, 429/503, checkpoint, dédup, secrets |
| E4 | M4 | Parsing : horodatage, multi-lignes, anomalies, TRUNCATE |
| E5 | M5 | Normalisation CIM : compléter le mapping, tester, versionner |
| E6 | M6 | Enrichissement : nouveau lookup, watchlist, performance |
| E7 | M7 | Routage : host/sourcetype/index, nullQueue, masquage |
| E8 | M8 | Ingestion et stockage : files, buckets, rétention, dimensionnement |
| E9 | M9 | Qualité : 8 contrôles, alerte, tableau de bord |
| E10 | M10 | Projet final : intégrer les journaux web |
| INC-01…10 | M10 | Incidents avec injection de panne (`incidents/`) |

Règles : un changement à la fois · preuve avant/après · jamais de secret dans un fichier versionné · pannes uniquement sur le lab.
