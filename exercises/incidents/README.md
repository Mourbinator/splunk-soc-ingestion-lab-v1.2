# Incidents d'ingestion — mode d'emploi
Chaque fiche contient : **Contexte** (le ticket), **Pré-requis**, **Injection** (à exécuter par le formateur/binôme ; l'apprenant ne la lit pas), **Symptôme**, **Méthode** (étapes guidées), **Indices** progressifs, **Livrable**, **Retour à la normale**.

Règles : état sain avant injection (`tests/ACCEPTANCE.md`), une panne à la fois, preuves avant de corriger, `docs/POSTMORTEM-TEMPLATE.md` à la fin.
Solutions détaillées : `instructor/ANSWER-KEY.md`.
